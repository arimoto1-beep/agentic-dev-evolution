# eラーニング動画のつくり方

## はじめに

社内向けの学習コンテンツは、文章よりも動画のほうが最後まで読まれやすいと言われます。とはいえ、動画をゼロから作るのは負担が大きい作業です。すでに書いた記事があるなら、それを教材の土台として使うのが現実的です。

この記事では、記事を動画教材に変えるまでの流れを整理します。

## 教材化の流れ

記事をそのまま読み上げても、教材としては分かりにくくなります。情報を一度スライドの単位に分け直す必要があります。

1. 記事を見出しごとに分割する
2. 見出しごとに要点を並べる
3. スライドに起こす
4. ナレーションを付ける
5. 動画として書き出す

### スライドに分ける基準

1 枚のスライドに情報を詰め込みすぎると、視聴者は文字を追うことに集中してしまいます。

- 1 枚あたりの情報量は、口頭で 30 秒から 60 秒で説明できる範囲にする
- 見出しは、そのスライドで話す内容をそのまま表す
- 箇条書きは、読み上げたときに意味が通る長さにする
  - 修飾の多い長文は分ける
  - 図で示せるものは図にする

> 教材の目的は、情報を渡すことではなく、理解してもらうことです。

## 変換を自動化する

手作業でスライドを作ると、記事を更新するたびに作り直すことになります。変換を自動化しておけば、記事を直すだけで教材を更新できます。

| 工程 | 入力 | 出力 |
| --- | --- | --- |
| 資料生成 | Markdown 記事 | プレゼンテーション |
| 画像化 | プレゼンテーション | スライド画像 |
| 音声生成 | 原稿 | ナレーション音声 |
| 動画生成 | 画像と音声 | 動画ファイル |

変換はコマンドとして実行できるようにしておきます。

```bash
note2slides article.md -o article.pptx
```

## まとめ

記事は、そのままでは教材になりません。スライドの単位に組み替えることで、はじめて教材として使えるようになります。

自動化できる部分を自動化し、人が判断すべき部分に時間を使うことが大切です。
